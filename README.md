# blog.getservices.ai
GetServices.ai blog (blog.getservices.ai), publisheddaily by seo-controller

## How this site works
- Published with GitHub Pages from `main` (root) at https://blog.getservices.ai (see `CNAME`).
- Articles are written into `blog/` by the daily blog bot in [seo-controller](https://github.com/shaheenarifch-arch/seo-controller) (site entry `blog.getservices.ai` in `sites.json`). The bot also rebuilds `blog/index.html` and adds new URLs to `sitemap.xml`.
- DNS (GoDaddy): CNAME record `blog` → `shaheenarifch-arch.github.io`. Help: https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site
